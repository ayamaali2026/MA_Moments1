MA Moments Startup MVP
======================

تشغيل المتجر:
1) افتحي مجلد المشروع في VS Code.
2) شغّلي Live Server على index.html.
3) واجهة المتجر: index.html
4) لوحة التحكم: admin.html

أهم الصفحات:
- index.html: الصفحة الرئيسية
- products.html: صفحة المنتجات والبحث الذكي
- product.html: تفاصيل المنتج
- cart.html: السلة
- wishlist.html: المفضلة
- admin.html: لوحة الإدارة

مهم:
هذه النسخة تحفظ المنتجات والسلة والمفضلة في LocalStorage داخل المتصفح.
هي MVP احترافية للواجهة وتجربة الإدارة، وليست بعد قاعدة بيانات مركزية.
للنشر التجاري الحقيقي يجب ربطها لاحقاً بـ Backend وقاعدة بيانات وتسجيل دخول آمن للإدارة.
